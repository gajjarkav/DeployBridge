# Phase 1 Report

## Introduction

Phase 1 of the DeployBridge project focused on the basic project setup and initial configuration. In this phase, we created the main folder structure for the backend, frontend, and support documents. The goal was to prepare a clean foundation for future development.

## Work Completed in Phase 1

The following work was completed during this phase:

- Created the main `DeployBridge` project folder.
- Set up the backend structure for API development.
- Added the core configuration files for application settings, logging, exceptions, and lifespan handling.
- Created the initial API routing structure.
- Added a basic health check API endpoint to test the backend setup.
- Prepared the frontend folder structure with template, static, CSS, asset, and JavaScript directories.
- Added support document files required for the academic project report.
- Added sample environment configuration files for backend setup.

## Backend Setup

The backend was prepared as the starting point for the application. It includes:

- `main.py` for starting the FastAPI application.
- `config.py` for environment-based settings.
- `logger.py` for logging support.
- `exception.py` for custom project exceptions.
- `lifespan.py` for startup and shutdown handling.
- `router.py` for API route registration.
- `health.py` for the first test endpoint.

This setup ensures that the project has a structured and maintainable backend from the beginning.

## Frontend Setup

The frontend structure was also prepared in this phase. It includes folders for:

- HTML templates
- CSS files
- JavaScript files
- Static assets

At this stage, the frontend is in the basic setup form and is ready for UI development in the next phases.

## Support Documents

The `SupportDocs` folder contains the required project documentation files such as:

- Title page
- Certificate
- Acknowledgement
- Abstract
- Index
- Chapters
- Weekly progress report

These files were organized to support report writing and project submission work.

## Environment Variables in phase 1 (Backend)
```
APP_NAME : application name 
APP_VERSION : application version
APP_DESCRIPTION : application description 
DEBUG : debug 
ENV_TYPE : environment type 
DOCS_URL : document url 
REDOC_URL : redoc url
HOST : host url 
PORT : port number
LOG_LEVEL : logllevel
```
