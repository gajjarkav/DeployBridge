# Phase 2 Report

## Introduction

Phase 2 of the DeployBridge project focused on GitHub OAuth authentication and user session setup. In this phase, we connected the application to GitHub so users can sign in with their GitHub accounts before using the deployment features.

## Work Completed in Phase 2

The following work was completed during this phase:

- Created the GitHub OAuth login flow for user authentication.
- Added backend support to exchange the GitHub authorization code for an access token.
- Fetched the authenticated GitHub user's profile and primary email.
- Stored GitHub user details in the database for later use.
- Added token and profile handling for authenticated sessions.
- Prepared the frontend login page to redirect users to GitHub authentication.
- Added callback handling so the frontend can complete login after GitHub redirects back.
- Verified the login flow using the existing FastAPI and SQLAlchemy backend structure.

## Backend Setup

The backend was extended to support GitHub OAuth authentication. It includes:

- `auth.py` for login and callback routes.
- `github.py` for GitHub token exchange and profile fetching.
- `user.py` for storing GitHub-linked user details.
- `security.py` for authentication-related helpers.
- `config.py` for GitHub OAuth client settings.

This setup allows the application to identify and authenticate users through GitHub before they access deployment features.

## Frontend Setup

The frontend was updated to support the OAuth login flow. It includes:

- A login page with a GitHub sign-in action.
- JavaScript code to request the GitHub login URL from the backend.
- Callback handling to capture the GitHub authorization code.
- Local storage support for the GitHub access token, username, and avatar.
- Automatic redirect to the dashboard after successful login.

At this stage, the frontend became connected to the GitHub authentication process and ready for repository-level features in the next phase.

## Technologies Used in Phase 2

The following technologies were used in this phase:

- FastAPI for backend API development
- GitHub OAuth for authentication
- HTTPX for calling GitHub API endpoints
- SQLAlchemy for database interaction
- PostgreSQL for storing user records
- Pydantic for request and response validation
- HTML, CSS, and JavaScript for the frontend login flow

## Environment Variables in phase 2 (Backend)
```
GITHUB_CLIENT_ID : GitHub OAuth client id
GITHUB_CLIENT_SECRET : GitHub OAuth client secret
GITHUB_REDIRECT_URI : GitHub OAuth callback url
```
